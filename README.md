## Security lens

- Threat modeling before implementation.
- Least privilege and explicit trust boundaries.
- Authorized testing and responsible disclosure.
- Reproducible findings instead of vague alarm signals.
- Human-readable explanations for automated decisions.
- Small, composable systems over unnecessary complexity.
